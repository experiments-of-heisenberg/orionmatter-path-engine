## Bugs (not fixed, per instructions — no failing tests written for them)

1. **`withLimit` stores NaN** — [limits.ts](/agent/workspace/orionmatter-path-engine/src/ui/limits.ts:63). `withLimit(c, NaN)` yields `maxMonths: NaN` (outside 1..240, non-integer); the label then reads "NaN months" and the API receives `null` on the wire. Fix: `if (Number.isNaN(months)) return normalise(c);`. No UI path produces NaN today, so severity is low.
2. **`cleanSkill`/`renameScenario` split surrogate pairs** — [limits.ts](/agent/workspace/orionmatter-path-engine/src/ui/limits.ts:90), [scenarios.ts](/agent/workspace/orionmatter-path-engine/src/ui/scenarios.ts:114). `cleanSkill("x".repeat(39) + "😀")` ends in a lone high surrogate. Fix: `Array.from(s).slice(0, 40).join("")`.
3. **Stale chat answer overwrites newer slider moves** — [usePathState.ts](/agent/workspace/orionmatter-path-engine/src/components/usePathState.ts:129). Ask "within 2 years", drag the slider to 36 while it works: on finish the limits snap to 24 and the slider move is lost. The `sent` constraints are already captured; suggested fix is to only auto-apply when the user hasn't moved since, otherwise offer Apply. Asserted as current behavior in `whatIfAppEdges.test.tsx`.
4. **`applyRelaxation` returns `undefined` for an unknown knob** — [limits.ts](/agent/workspace/orionmatter-path-engine/src/ui/limits.ts:133). No `default` case; typed away but runtime-unsafe. Fix: add `default: return c;`.
5. **`.applied__change` has no CSS rule** — used in [Chat.tsx](/agent/workspace/orionmatter-path-engine/src/components/Chat.tsx:45), absent from `globals.css` (verified). Harmless (grid placement comes from the parent); carried on the new test's allowlist with a reason.
6. **Drafts lost on tab switch** — chat draft, skill input, and scenario rename field are local `useState` in components that unmount when leaving the What if tab. Type half a message, visit Map, come back: it's gone. Fix: lift draft state into `usePathState`.
